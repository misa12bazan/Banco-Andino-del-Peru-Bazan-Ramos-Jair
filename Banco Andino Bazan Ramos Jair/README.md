# Banco Andino Perú - Apertura de cuenta (Semana 7)
1. Neon: crea proyecto, abre SQL Editor y ejecuta sql/01_tablas.sql y luego sql/02_datos_prueba.sql (una vez).
2. Neon > Connect: copia la connection string y pégala en js/config/neon-config.js.
3. Prueba en local con Live Server (VS Code) abriendo index.html.
4. Cuentas de prueba (clave 1234): cliente1@correo.com ... cliente10@correo.com, admin@correo.com, empleado1@correo.com, empleado2@correo.com.
5. Vercel: sube la carpeta como proyecto estático.
